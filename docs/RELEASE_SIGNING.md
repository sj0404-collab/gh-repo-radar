# Постоянный release key

NimbusDeck использует отдельный ключ обновлений для пакета
`com.sj0404.nimbusdeck`. Ключ **не хранится в Git**: каталог
`.local-signing/` полностью исключён через `.gitignore`.

## Готовая локальная копия

В рабочем окружении создан файл:

`./.local-signing/NimbusDeck-signing-backup-KEEP-PRIVATE.zip`

В архиве находятся PKCS#12-keystore, параметры Gradle и файл с паролем.
Скачайте архив, сохраните минимум две зашифрованные резервные копии и удалите
лишние незашифрованные копии. Не отправляйте архив в чат, issue, commit или
release.

Параметры сертификата:

- алгоритм ключа: RSA 4096;
- подпись сертификата: SHA256withRSA;
- срок: 100 лет;
- alias: `nimbusdeck`;
- SHA-256 fingerprint:
  `06:65:45:CF:50:C8:3F:EF:8D:E1:99:2A:74:1D:BE:0D:05:23:E9:AC:7D:78:C3:D0:52:23:96:99:90:CE:A2:BA`.

## Сборка обновлений

1. Распакуйте закрытый backup в `.local-signing/`.
2. Не меняйте `applicationId` и не создавайте новый ключ.
3. Увеличьте `versionCode` и `versionName` в `app/build.gradle.kts` и manifest.
4. Выполните `./scripts/build-release.sh`.
5. Сверьте fingerprint APK с указанным выше.

Если ключ утрачен, уже установленное приложение нельзя обновить обычным APK:
пользователям придётся удалить его и поставить приложение с новым ключом.
