# NimbusDeck

Независимый Android-лаунчер облачного гейминга с новым брендом и современным
адаптивным интерфейсом. Он открывает **официальный GeForce NOW**, если клиент
установлен, либо ведёт на его официальную страницу в Google Play.

> NimbusDeck не является модифицированной копией GeForce NOW, не подменяет его
> API и не связан с NVIDIA. Оригинальные split-APK не включаются в приложение и
> удалены из текущего дерева репозитория.

## Что готово

- оригинальное имя, package ID `com.sj0404.nimbusdeck` и новый логотип;
- адаптивный интерфейс для телефона, планшета и Android TV;
- быстрый запуск официального клиента и переход к установке при его отсутствии;
- карточки состояния сети, клиента и требования авторизации;
- русская, украинская и английская локализации;
- отсутствие собственной регистрации, аналитики и фонового сервиса;
- постоянный RSA-4096 release key вне Git;
- minSdk 23, targetSdk 35.

## Обязателен ли вход в аккаунт?

**Да, для самого GeForce NOW вход обязателен.** NVIDIA и подключённые магазины
управляют подпиской, библиотекой, лицензиями и облачными сессиями. NimbusDeck не
может и не должен обходить эту авторизацию. Вход происходит только внутри
официального клиента; лаунчер не получает и не хранит пароль.

## Сборка

Откройте проект в Android Studio или используйте Gradle Wrapper (JDK 17):

```bash
./scripts/build-release.sh
```

Подписанный APK появится в `output/NimbusDeck-1.0.0-release.apk`.
Локальный ключ должен находиться в `.local-signing/`; подробности и правила
резервного копирования — в [docs/RELEASE_SIGNING.md](docs/RELEASE_SIGNING.md).

Для полностью нового ключа (только до первой публикации):

```bash
./scripts/create-release-key.sh
```

Скрипт откажется перезаписывать уже существующий ключ.

## Архитектура и приватность

Приложение написано на Java и использует только Android Framework без рекламных
и аналитических SDK. Единственное разрешение — `ACCESS_NETWORK_STATE` для
индикатора подключения. Package visibility ограничена официальным пакетом
`com.nvidia.geforcenow`.
